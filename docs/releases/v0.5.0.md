# v0.5.0 — frictionless in-window UX and native `lazyos-greeter`

Everything interactive stays inside its window, anticipates what you opened it
for, and keeps tool actions separate from domain results. At boot, `tuigreet`
is retired: `greetd` now launches **`lazyos-greeter`**, a native Ratatui login
surface themed from the same palette engine as the desktop session, with its
own defaults editor.

## What changed since v0.4.3

### Frictionless in-window UX (spec 020)

- **Anticipate primary intent on open**:
  - `lazyos menu net` renders cached Wi-Fi networks immediately while triggering a
    background rescan in-place.
  - `lazyos menu bluetooth` scans automatically on open and right after power-on.
  - `lazyos menu clean` computes reclaimable cache space asynchronously before
    confirmation.
  - `lazyos menu calc` evaluates expressions live as you type with a movable
    cursor and Python-style operators.
- **In-window tool lifecycle and transient/persistent notices (`ActionNotice`)**:
  - Short actions show an in-window braille spinner and status banner instead of
    closing the menu and emitting external `notify-send` toasts.
  - Heavy multi-step or streaming tasks run inside `TaskView` with step checklists,
    progress bars, and persistent completion cards.
  - Routine discovery clears its status on completion, positive transitions
    auto-clear after 3 seconds, and actionable errors or space-freed summaries
    persist until dismissed.
- **Separate actions from domain results (`ActionStrip`)**:
  - Tool-level actions (`Rescan`, `Share QR`, `Clean all safe`, `Mute`, `Mixer`,
    `Refresh`, `Save PNG`, `Settings`, …) live in a dedicated horizontal
    `ActionStrip` (`Tab` / `Ctrl+<Key>` / mouse click), leaving `ListState` strictly
    for domain rows.
  - Generated QR codes (`menu qr` and `menu net` Share QR) save high-resolution
    PNGs (`s` / `Ctrl+S`) under `~/Pictures/Screenshots/<YYYY-MM-DD>/`.
- **Headless voice-to-text dictation (`dictate`, `Alt+Ctrl+X`)**:
  - Holding `Alt+Ctrl+X` records push-to-talk and transcribes on release via
    `taskset -c 4-7 whisper-cli -t 4` without stealing Wayland keyboard focus
    from `wtype`.
  - A quick tap or Root Menu launch starts hands-free recording with synchronized
    stop/cancel controls across `lazyos-notify` action buttons, Waybar's
    `custom/busy` spinner (`bar-busy`), and the Root Menu's dynamic
    `Stop dictation` row.
- **UI & build fixes**: adopted `foot` auto-copy defaults, isolated the private
  D-Bus test bus in `tests/notify.rs` over abstract `/tmp/dbus-*` sockets for CI
  runners, and polished density-aware card geometry, live window resizing, and
  inline previews.

### Native `lazyos-greeter` & Greeter Settings (spec 021)

- **`lazyos-greeter` replaces `tuigreet` 0.9.1**:
  - Implemented as the `greeter` command inside `lazyos` (`/usr/bin/lazyos-greeter
    -> /usr/bin/lazyos`, `Shape::Full`) over a pure-Rust `UnixStream` JSON `greetd`
    IPC client (`src/greeter/ipc.rs`).
  - `/usr/bin/lazyos-greeter --session` generates theme-matched `foot.ini`,
    `sway.conf`, and wallpaper PNG assets, then launches minimal `sway` +
    fullscreen `foot` on VT7—automatically falling back to inline Ratatui TUI on
    the raw console if `sway` or `foot` cannot start (`--tty` forces the TTY
    path).
  - Supports clickable user pills + `[+ Other]` manual login, masked PAM
    secrets and multi-step challenges, Wayland/X11 `.desktop` session discovery
    (`DesktopNames` exported as `XDG_CURRENT_DESKTOP`), live theme cycling across
    all 16 palettes (`F4` / `Ctrl+T`), session switching (`F2` / `Ctrl+S`),
    Cancel-first confirmations for Sleep / Reboot / Shut down, and safe
    in-session testing via `lazyos greeter --preview`.
- **Interactive Greeter Settings (`lazyos menu greeter` / `lazyos greeter settings`)**:
  - Accessible from **Settings → Login screen (Greeter)**, the Command Palette
    (**Greeter settings**), or **`Ctrl+G`** / **`F9`** / **Settings** inside
    `lazyos greeter --preview`.
  - Configures `/etc/lazyos/greeter.toml` (`follow_user_theme`, fixed/default
    `theme`, `show_user_pills`, `remember_user`, `default_session`,
    `remember_session`, `clock_24h` 24h/12h toggle, `show_power_actions`, and
    custom `greeting` text) with inline searchable pickers and Cancel-first reset
    to defaults.

## Assets

When published by `.github/workflows/release.yml`, the release attaches the
verified `aarch64` framework binaries built from this tag (`lazyos` and
`spike-sixel`) alongside `SHA256SUMS`. Full microSD/eMMC disk images continue to
be built directly on-device via `scripts/build.sh` and sanitized by
`scripts/lib-dist.sh`.
